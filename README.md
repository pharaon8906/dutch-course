# Taalfiets A1.2 — нідерландська для українців

Інтерактивний курс нідерландської мови рівнів A0–A2.

- **Рівні A0, A1, A2** зі «шляхом рівня»: слова, діалоги, тексти, граматика
- **540 слів** у 21 темі (з розмовними виразами), з картинками й озвучкою
- **Картки** з інтервальним повторенням (1, 2, 4, 7, 14, 30 днів)
- **Тренажер**: переклад, на слух, написання, гра «de чи het?», підказки
- **16 побутових діалогів** двома голосами; **🎤 мікрофон**: кажеш свою репліку — правильно йдеш далі, ні — повторюєш
- **6 текстів для читання** (по 2 на рівень, ≈5 хв): торкнись слова — вимова й переклад
- **Звуки й букви**: абетка, усі голосні, дифтонги, приголосні й закінчення з прикладами, гра «Вгадай звук»
- **Граматика**: 35 тем простими словами (по рівнях A0–A2), з типовими помилками українців, тестами і таблицею 30 неправильних дієслів з озвучкою
- **Тренажер**: переклад, на слух, написання, de/het, граматика, неправильні дієслова, диктант, «Скажи вголос»
- **Вимова**: складні звуки, повільне прослуховування, скоромовки
- **Лайфхаки**, «фальшиві друзі», набір фраз для виживання
- Прогрес, серія днів і бали досвіду зберігаються в браузері

## Як відкрити

Відкрийте `index.html` у будь-якому браузері. Усі 830 аудіозаписів вбудовані у файл (близько 4 МБ), тому курс працює навіть без інтернету.

## Структура

| Шлях | Що це |
|---|---|
| `index.html` | Готовий курс, один файл |
| `src/app.html` | Готовий інтерфейс (збирається з частин) |
| `src/content2.js` | Рівні, діалоги, вирази, абетка, звуки, граматика |
| `src/content3.js` | Додаткові 16 тем граматики, неправильні дієслова |
| `src/texts.js` | Тексти для читання |
| `src/gloss.js` | Переклад кожного слова з текстів |
| `src/views.js` | Логіка розділів і мікрофона |
| `src/words.js` | 500 слів у форматі «слово, переклад, підказка» |
| `src/content.js` | Діалоги, граматика, звуки, лайфхаки, фальшиві друзі |
| `src/emoji.js` | Картинки до слів і тем |
| `src/extract.js` | Збирає всі фрази для озвучки у `src/tts/items.json` |
| `src/gtts.py` | Записує аудіо голосами Google Chirp 3 HD у `src/tts/gmp3/` |
| `src/pack.py` | Обрізає тишу, вирівнює гучність, пакує в `src/audio/*.json` |
| `src/gen.py` | Запасний варіант: офлайн-голоси Piper |
| `src/build.py` | Збирає `index.html` |

## Як перезібрати

```bash
cd src
node extract.js        # після зміни слів чи діалогів
GKEY=ваш_ключ python3 gtts.py all   # Google Cloud Text-to-Speech, ключ API
python3 pack.py        # потрібен ffmpeg
python3 build.py       # створює ../index.html
```

Озвучка: Google Chirp 3 HD, голоси `nl-NL-Chirp3-HD-Kore` (жіночий) і `nl-NL-Chirp3-HD-Charon` (чоловічий).
Ключ API передається тільки через змінну `GKEY` і ніколи не зберігається в репозиторії.

Запасний офлайн-варіант — `gen.py` з голосами Piper (`nl-rdh-medium`, `nl-mls_7432-low`) з релізу
[rhasspy/piper v0.0.2](https://github.com/rhasspy/piper/releases/tag/v0.0.2), розпакованими в `src/voices/`.
